# Sentiment Pair Review

Browser-based independent annotation of 20 pilot and 400 main text pairs.

## Use
Open the GitHub Pages site. Load the blinded JSON file provided privately by the coordinator, enter your assigned reader code, and complete the pilot. Begin main coding only after the coordinator confirms the final codebook.

The study file is read locally and never uploaded. Answers are saved in your browser under your reader code. Re-load the same study file and use the same code to resume. Export JSON backups regularly and send your exported CSV to the coordinator. Reader codes are local storage namespaces, not passwords. Use separate devices/browser profiles for independent coders.

## Data separation
Only application source is published. Research texts, sampling keys, model predictions, credentials and annotations are excluded. Do not commit these files to this repository.

## Deployment
GitHub Pages: deploy from the main branch, root folder. No build required.
